# 全球封測最前線｜品牌與工作流待辦

建立日期：2026-05-03

## 待辦 1：關於頁面補品牌概念

需要在網站「關於全球封測最前線」頁面補上品牌定位。

核心概念：

- 第一層：第一手資訊整理。優先從公司官網、IR、News、R&D、Products 取得資訊，這是品牌核心精神。
- 第二層：全球資訊掃描。後續再輔助國外財經報導、國內財經報導、專業電子報、雜誌與產業媒體，做快速掃描、摘要與分類。
- 品牌要讓一般投資人理解：除了分析師、電視新聞與財經報導之外，這裡提供「最前線第一手資訊」與「全球外語 / 華語網站快速掃描」。
- 文章與電子報維持資訊共享，不做投資建議。
- 隨資料庫變大，翻譯、摘要與來源資料都要留存，方便交叉比對、引用與後續調度。

品牌概念意象圖待使用者提供範本後再生成。初步視覺方向：清新藍色系、科技感、簡單明瞭、不過度炫麗、不暗沉。

## 待辦 2：第 2/3 週擴充公司來源名單

使用者會看 YouTube 影片、介紹不同封測應用領域，整理海內外關聯企業名稱。

後續工作方式：

1. 使用者提供公司名稱。
2. Codex 依公司名稱尋找官網、IR、News、R&D、Products、技術頁與產品頁。
3. 使用者手動確認網址。
4. 確認後陸續加入來源名單。
5. 第 2/3 週目標逐步建立 50-100 家公司名單與網址。

## 待辦 3：文章代表圖風格

每篇正式文章或電子報可在開頭加入 1-3 張代表圖。用途：

- 幫讀者快速理解主題。
- 做為網站文章與未來 Podcast 輪播素材。
- 圖片搭配約 100 字科普說明。

初步風格：

- 淺色背景、藍色系列、清新科技感。
- 簡單明瞭，偏科普與製程示意。
- 避免太炫麗、太暗沉、太像科幻海報。
- 不放公司 logo，不做投資暗示。

## 待辦 4：Obsidian 知識網路

目前已寫入：

後續建議把 Obsidian 拆成幾類筆記：

- 來源地圖：公司、URL、入口類型、抓取難度、用途。
- 來源文章：每篇原文或產品頁的標題、URL、摘要、中文整理、供應鏈位置。
- 公司卡片：每家公司固定一頁，連回相關來源文章。
- 技術卡片：例如切割、研磨、點膠、散熱片、ABF、玻纖布。
- 文章 / 電子報草稿：每篇公開內容連回來源文章與技術卡片。

這樣之後可以用「公司 -> 技術 -> 來源 -> 文章」的方式追溯，也方便 Podcast 腳本或電子報調度。
